## ✨ Características

- 📱 **Diseño Responsivo** — Se adapta perfectamente a móviles, tablets y desktops
- 🎨 **Tema Oscuro Profesional** — Paleta de colores cuidadosamente seleccionada con acentos cyan
- ⚡ **Rendimiento Optimizado** — Sin frameworks pesados, carga ultrarrápida
- ♿ **Accesible** — Contraste WCAG AA+, aria-labels, navegación por teclado
- 🏗️ **HTML Semántico** — Estructura limpia con `<header>`, `<main>`, `<section>`, `<article>`, `<footer>`
- 🎭 **Animaciones Suaves** — Intersection Observer para reveal on scroll, efecto de typing
- 🧭 **Navegación Intuitiva** — Smooth scroll, navbar fija, menú hamburguesa responsive

## 🛠️ Instalación Local

1. Clona el repositorio:
```bash
git clone https://github.com/Jlebot7/PortFolio.git
```

2. Abre `index.html` en tu navegador:
```bash
cd PortFolio
start index.html
```

No se necesitan dependencias ni build tools. ¡Puro HTML, CSS y JavaScript! 🎉
